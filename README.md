# Hangman Game

A simple text-based Hangman game built using Python.

## Features

- 5 predefined words
- Random word selection
- Maximum 6 incorrect guesses
- Letter-by-letter guessing
- Console-based gameplay

## Technologies Used

- Python
- Random module
- While loop
- If-else
- Lists
- Strings

## How to Run

```bash
python hangman.py
