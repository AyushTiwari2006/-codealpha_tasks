# Task 4: Basic Chatbot 🤖

## 📌 Project Overview

This project is a simple **rule-based chatbot** built using Python.

The chatbot takes input from the user and provides predefined responses based on specific keywords or phrases.

## 🎯 Objective

Build a basic chatbot that can:

- Respond to greetings
- Answer "How are you?"
- Say goodbye when the user exits
- Handle unknown inputs

## 🛠️ Technologies Used

- Python
- if-elif-else
- Functions
- While loop
- Input/Output
- String handling

## 💬 Supported Commands

| User Input | Chatbot Response |
|------------|------------------|
| `hello` | Hi! |
| `how are you` | I'm fine, thanks! |
| `bye` | Goodbye! |
| Other input | Sorry, I don't understand that. |

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or terminal.
4. Run the following command:

```bash
python chatbot.py
